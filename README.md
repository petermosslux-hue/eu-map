# The European Union Family Map

A child-friendly map of the EU showing every member's name (in capitals), capital city and the year it joined.

- `index.html`: interactive version. Click a button (for example "2004 · The Big Party") to light up everyone who joined in that wave, or click any country.
- `eu-map.png`: static picture for sharing.
- `eu-map.svg`: vector version of the same map.
- `build.js`: script that generates all of the above (`npm install && node build.js`).

Open `index.html` in any browser. Map data: Natural Earth via the `world-atlas` package.
